🧩 Tech Stack
Frontend: Next.js
Backend + DB: Supabase
Payments: Razorpay
Hosting: Vercel
Communication: WhatsApp
🎯 What You’re Building

A subscription-based food delivery platform with:

👤 User Side
Browse menu & plans
Subscribe (enter details + pay)
Get confirmation (web + WhatsApp)
🧑‍💻 Admin Side
Manage products & plans
View all orders
Track active subscriptions
Create manual orders
Monitor payments
🧠 Core Architecture Principle

✅ Order is created BEFORE payment
✅ Payment is verified via webhook
✅ Subscription is created AFTER payment
